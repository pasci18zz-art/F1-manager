# F1 Manager

Meisterschafts-App für die Karriere im F1-Spiel: Wertung, Rennwochenenden, Statistiken, Titelprognose und Teamentwicklung.

- `index.html` – die fertige App, einfach im Browser öffnen
- `src/` – Quellcode (`style.css`, `body.html`, `app.js`)
- `build.sh` – baut aus `src/` die Dateien `index.html` und `dist/f1-manager.html` (Version für claude.ai)

Daten bleiben auf dem Gerät. Über Einstellungen → Daten & Sync lassen sie sich als Text oder Datei sichern
und auf einem anderen Gerät wieder einfügen. Sicherungen der alten HTML-Datei (F1 Karriere – Meisterschaftstabelle)
werden beim Import erkannt.
